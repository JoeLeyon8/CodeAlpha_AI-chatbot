# AI Chatbot

## Overview

AI Chatbot is a console-based Java application that enables interactive communication between users and a chatbot. It uses rule-based logic and basic Natural Language Processing (NLP) techniques to understand user input and provide predefined responses. This project demonstrates Java programming concepts such as loops, conditional statements, strings, and user input handling.

---

## Features

- Interactive text-based conversation
- Rule-based response system
- Basic NLP using keyword matching
- Handles frequently asked questions
- Case-insensitive user input
- Easy to extend with new questions and responses
- Beginner-friendly Java project

---

## Technologies Used

- Java
- Scanner Class
- String Manipulation
- Conditional Statements
- Loops
- Rule-Based NLP

---

## How to Run

1. Open the project in OnlineGDB, Eclipse, IntelliJ IDEA, or VS Code.
2. Compile the Java program.
3. Run the application.
4. Type your questions in the console.
5. Type **bye** to end the conversation.
